# Welcome to Blog App

This is a **blog list application** built with Next.js, featuring user authentication, blog management, and a personal reading list.

## Features

- **Blogs** - Add blogs, like them and search them by title
- **User Profiles** - See the blogs each user has added
- **Authentication** - Login and registration
- **Reading List** - Collect blogs to read and mark them as read
- **API Token** - Access your own data through the API

## Getting Started

To start exploring:

1. [Register](/register) for a new account
2. [Login](/login) to access your profile
3. [Create a new blog](/blogs/new)
4. View [all blogs](/blogs) and [users](/users)
